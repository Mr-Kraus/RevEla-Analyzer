# M02 - Indicator Catalog

Em conformidade com o CA-03, foram mapeados os indicadores exportados nativamente pelo `Final Reliability Indices.csv`.

## 1. Global Adequacy Indices (Índices Globais de Adequação)
| Indicador | Descrição Física | Unidade |
| :--- | :--- | :--- |
| **LOLP** | Loss of Load Probability | probabilidade (pu) |
| **LOLE** | Loss of Load Expectation | horas/ano |
| **EPNS** | Expected Power Not Supplied | MW |
| **EENS** | Expected Energy Not Supplied | MWh/ano |
| **LOLF** | Loss of Load Frequency | ocorrências/ano |
| **LOLD** | Loss of Load Duration | horas/ocorrência |
| **LOLC** | Loss of Load Cost | $/ano |

## 2. Escopos Identificados
Os mesmos indicadores acima são repetidos pelo ReLeVa nos seguintes escopos:
* **Total Global** (Sistema Inteiro)
* **By Failure Type** (Agrupado por causa: Geração, Transmissão, Mista)
* **By Region** (Agrupado geograficamente)
* **By Bus** (Agrupado topologicamente por Barra)
