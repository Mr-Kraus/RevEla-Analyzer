2. ABOUT REVELA ANALYZER

Revela Analyzer is a software tool developed to read, organize, query, analyze, and visualize data from files generated by software used for the simulation of electric power systems.

The software may process data generated by Revela and PS-MORA, developed in the context of LabPlan and INESC, according to the file formats and versions supported by the installed version of Revela Analyzer.

Revela Analyzer does not perform electric power system simulations.

The software does not replace the programs responsible for running simulations and is not, by itself, a tool for performing calculations or running new simulations.

Its purpose is to work with data that has already been generated by other simulation software and to provide functions for organizing, querying, analyzing, and visualizing that data.
